高德 JS API 属于需要自行申请 Key 的服务，本项目不内置任何密钥。 Key 只保存在本机浏览器的 localStorage，不会上传。

申请入口：console.amap.com/dev/key/app → 创建新 Key → 服务平台选「Web端(JS API)」。 个人使用请配置 Referer 白名单（填 localhost 或 127.0.0.1），避免 Key 被盗用。
